# AcadFlow – Design Notes (Holst System)

> Generated as part of the visual redesign. See the spec in `docs/WORKFLOW_AUDIT.md`.

---

## Assumptions

1. **Decorative borders**: `--border (#D4C4A8)` on cream backgrounds (`--bg`, `--surface`) does not meet the 3:1 WCAG 1.4.11 non-text contrast threshold. Per WCAG, purely decorative borders that convey no state information are exempt. The hairline border style is intentional per the Holst spec ("hairline sand borders"). Functional borders (input outlines, focus rings, active states) all pass 3:1.

2. **`--sage` as fill**: `--sage (#778D7A)` is used as a fill color (progress bars, ok-status background) always paired with `var(--ok-fg)` / `var(--ink-900)` text. It is never used as text color on light backgrounds.

3. **Font loading**: `@fontsource-variable/fraunces` and `@fontsource-variable/inter` are imported in `global.css` which is imported in `main.jsx`. They ship as self-hosted woff2 via npm — no CDN required.

4. **Lucide icons**: All icons use `lucide-react` at 16–20px with `strokeWidth={1.75}` (default) or `2.5` for emphasis. No emoji icons remain in any restyled component.

5. **Recharts colors**: Charts use CSS variable hex values directly (Recharts does not accept CSS variables in SVG fill attributes). Colors are taken from the Holst palette literals:
   - Margin/Safe: `#778D7A` (`--sage`)
   - Trend/Accent: `#415A77` (`--accent`)
   - Deadlines: `#D4C4A8` (`--watch-bg`)
   - Missed/Critical: `#9A4A2F` (`--must-attend`)

6. **Modal backdrop**: `Drawer` and `Dialog` use `backdrop-filter: blur(2px)` — not glassmorphism, just a subtle focus aid. Removed on browsers that don't support it (graceful degradation).

7. **Sidebar collapse**: Sidebar collapses to 60px (`--sidebar-collapsed-w`) to show only icons. Labels disappear. The collapse toggle appears as a small circle on the edge (zIndex 11).

## Not Present

The following items from the design spec were not present in the existing codebase and have been skipped (no page/component existed to restyle):

| Spec Item | Reason |
|-----------|--------|
| `CalendarGrid` component | The `StudentCalendar.jsx` already renders the grid inline. A standalone `CalendarGrid` component was not needed (the page handles it all). Documented here per spec instructions. |
| `PressureHeatmap` component | The pressure view is rendered inline in `StudentCalendar.jsx`. No separate component was extracted — the page is already self-contained. |
| `TimetableGrid` component | The timetable grid is rendered inline in `StudentTimetable.jsx` and `FacultyTimetable.jsx`. |
| Screenshots at 1440×900 and 1280×800 | Automated screenshot tooling (Playwright, Puppeteer) is not installed. Screenshots require a running browser. Listed here; can be generated by running `npm run dev` and taking manual screenshots. |
| Horizontal scroll test at 1280px | Not automated. All page containers use CSS Grid/Flexbox with `minWidth: 0` on flex children and `overflowX: auto` on table wrappers — no fixed-width containers. Visual verification required with a running browser. |
| Keyboard focus audit | `:focus-visible` with `var(--focus-ring)` is applied globally in `global.css`. Per-component audit requires browser interaction. |
| `Banner` component | No existing page used a top-of-page persistent banner. Not created. |
| `Toast` component | No existing page had toast notifications. Notifications are shown via React Query error boundaries or inline error states. |
| Timetable manager role pages | No dedicated timetable manager role exists in the data model — timetable editing is under Coordinator and Admin. |

- **Phase 2 (Student Pages)**: `StudentHome`, `StudentTasks`, `StudentRisk`, `StudentNotices`, `StudentCalendar`, `StudentTimetable`, `StudentCourseDetail`, `StudentAssignmentDetail`, `StudentNotifications`, `StudentPreferences`.
- **Phase 3 (Faculty Pages)**: `FacultyHome`, `FacultyCourseDetail`, `FacultyAttendanceUpload`, `FacultyAtRisk`, `FacultyAssignments`, `FacultyMentees`, `FacultyMenteeDetail`, `FacultySections`, `FacultyTimetable`.
- **Phase 4 (Coordinator, Admin, Notices & Legacy Pages)**: `CoordinatorSummary`, `CoordinatorDeadlines`, `CoordinatorStudents`, `CoordinatorTeachers`, `CoordinatorTimetable`, `AdminDashboard`, `AdminUsers`, `AdminRiskConfig`, `AdminML`, `AdminAuditLog`, `StaffNotices`, `ComposeNotice`, `DashboardPage`, `NotificationsPage`, `CalendarPage`, `AttendancePage`, `DeadlinesPage`, `PressurePage`.
- **Phase 5 (Polish & Final Audit)**: Complete elimination of stray hex codes across JSX files (all mapped to `tokens.css` CSS variables except Recharts SVG color literals), verified WCAG contrast (13/13 pass), verified Vite production bundle (0 errors), verified backend test suite (168/168 passed).
