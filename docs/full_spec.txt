=== B. CALCULATION CONTRACT (must match exactly) ===
required = ceil(0.75 * total_classes); still_need = max(0, required - attended); remaining = total_classes - held (holidays excluded); buffer = remaining - still_need.
Negative buffer -> show "Not recoverable by attendance alone" (never as an error). Late counts as attended. A student enrolled mid-semester is judged only on classes on or after enrolled_on. Zero remaining classes must never divide by zero.
Risk score 0-100: Margin 50 x (1 - buffer/remaining), full 50 if buffer < 0; Trend 20 (slope of last 2 weeks); Deadlines 20 (count and weight of unsubmitted graded work due in next 14 days); Missed 10 (share of submissions marked missed). Bands: 0-29 Safe, 30-54 Watch, 55-79 At risk, 80-100 Critical. Weights and thresholds come from risk_config (DB), and each snapshot stores config version.
Minimum evidence: no status until min_classes (default 8) have been held; show "Not enough data yet".
ML estimate (probability of finishing below 75%) is shown beside the rule score as "Model estimate, extra signal". If the ML service is down show "Model score unavailable" and keep the rule score.
Unit-test fixtures (course of 60 classes, required 45): Riya held 40 attended 30 -> buffer 5, margin 37.5. Aman 40/36 -> buffer 11, margin 22.5. Meera 40/40 -> buffer 15, margin 12.5. Karan 50/30 -> buffer -5, margin 50 (not recoverable). Dev held 5 -> "Not enough data yet".
Planned-leave projection (per course): planned = number of marked future class days; spare_misses_left = buffer - planned; projected_final_percent = (attended + remaining - planned) / total_classes. spare < 0 -> "Not recoverable by attendance alone". Projection never changes the official risk score.
Must-attend day: an exam/review is held or due that day, OR missing all of that day's classes of any course would make (buffer - classes_that_day_in_that_course) < 0 (in plan mode, use the buffer after already planned absences). Otherwise label "Optional".
Pressure score per day = sum of deadline weights due that day (exam 4, review 3, assignment 2, lab file 2, notice deadline 1) + 0.5 x sum of weights due in the next 3 days + 1 if must-attend + 1 if 4 or more classes that day. Levels: 0 none, 1 low (<3), 2 medium (3 to <6), 3 high (>=6). Constants live in config. Show level as shade + number + icon.
